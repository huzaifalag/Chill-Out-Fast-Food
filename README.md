# 🍟 Chillout Fast Food

> **A modern fast-food website designed to bring a real restaurant experience to the web.**

Chillout Fast Food is a restaurant website project created with a focus on **modern design, responsive layouts, food presentation, and an intuitive customer experience**.

## ✨ Features

* 🍔 Modern fast-food interface
* 📱 Fully responsive design
* 🍕 Attractive menu presentation
* 🥤 Food & drink sections
* 📍 Restaurant information
* 📞 Contact section
* 🎯 Strong call-to-action elements
* ⚡ Lightweight frontend
* 🎨 Custom visual styling

## 🛠️ Built With

| Technology | Purpose                      |
| ---------- | ---------------------------- |
| HTML5      | Website structure            |
| CSS3       | Styling & responsive design  |
| JavaScript | Interactions & functionality |
